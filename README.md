# TasksAPI (.NET 8 Minimal API)

Web API RESTful para gerenciamento de tarefas desenvolvida em C# com **.NET 8**, **Entity Framework Core**, **PostgreSQL** e **Docker**.

## 🚀 Como Executar

Não é necessário ter o .NET SDK ou o PostgreSQL instalados na sua máquina local. Você só precisa ter o **Docker** e o **Docker Compose** instalados.

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/Juliamdev/TasksApiSolution.git](https://github.com/Juliamdev/TasksApiSolution.git)
   cd TasksApi
